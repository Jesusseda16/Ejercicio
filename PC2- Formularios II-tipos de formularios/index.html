Elementos de un formulario Web

HTML ofrece diferentes controles...

Campo de texto

Permite escribir una línea de texto <input type="text">

Contraseña

Texto oculto por seguridad <input type="password">

Correo electrónico

Para direcciones de email <input type="email">

Número

Permite introducir números <input type="number">

Teléfono

Para números de telefono <input type="tel">

URL

Para direcciones web <input type="url">

Búsqueda

Campo de Busqueda <input type="search">

Fecha

Permite introducir fechas sin más <input type="date">

Hora

Selector de hora <input type="time">

Semana

Selector de hora <input type="week">

Mes

Selector de mes <input type="time">

Fecha y hora

Selector de fecha y hora <input type="datetime-local">

Color

Selector de color <input type="color">

Rango

Selector de un valor en un rango <input type="range">

Checkbox

Casilla de verificacion <input type="checkbox">
